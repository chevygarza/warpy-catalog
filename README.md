# warpy-catalog

El catálogo de eventos de [Warpy](https://github.com/chevygarza/WifgetWorld), publicado como JSON estático.
La app lo descarga de `https://raw.githubusercontent.com/chevygarza/warpy-catalog/main/events.json`.

**No se edita aquí.** Lo publica GitHub Actions desde el repo de la app cada vez que `events.json` cambia y
pasa validación y Navi. Para cambiar algo, ver `docs/agent.md` en el repo de la app.
